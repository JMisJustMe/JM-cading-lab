# JM Authority Hold Engine v0.1

A working embodiment of **THE INSTRUCTION HANDOFF v1.0 — Authority, Probe, Persistence & Legitimate State Change**.

> **Later is not automatically stronger.**

## Open first

Open `OPEN_FIRST.html` through GitHub Pages. The interface works on phone and laptop, persists the live state in local storage, can install as a PWA, and exports/imports JSON handoff receipts.

## Operating route

`CURRENT GOVERNANCE + CHALLENGE → AUTHORITY HOLD → VALIDATION → CONTINUE OR HANDOFF → TRACE`

## Included bodies

- instruction packet builder;
- persistent governing-state machine;
- challenge classification;
- source, authority, scope, release, boundary, executability and trace gates;
- original-probe scenario;
- valid release-key scenario;
- higher-boundary suspension;
- courtesy re-entry test;
- breach recording without false release;
- expiry handling;
- JSON receipts, copy, export and import;
- local persistence and offline PWA shell;
- testable ES module kernel.

## Claim boundary

This engine supports explicit instruction-governance decisions. It does not prove hidden identity, motive or authority merely from wording, account access or channel continuity. Human, safety, legal and institutional decisions still require context appropriate to their consequences.
