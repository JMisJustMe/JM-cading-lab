# Readable Source Gate

Before v0.2 is claimed as remotely complete:

1. Every executable source file must exist in the canonical folder.
2. Remote hashes must match `SHA256SUMS.txt`.
3. The 19-test suite must be present and runnable.
4. The surface gate must pass.
5. A standing CI workflow must be mounted.
6. The final receipt must preserve the transport correction rather than conceal it.
