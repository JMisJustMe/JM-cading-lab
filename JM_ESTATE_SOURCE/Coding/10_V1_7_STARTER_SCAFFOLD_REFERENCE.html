WHAT v1.7 DOES:
- provides a clean starter HTML body,
- includes default inherited UX CSS,
- includes default inherited UX JavaScript,
- includes direct copy/open/download functions,
- includes inline status slots,
- makes manual fallback recovery-only,
- includes build checklist,
- includes receipt template,
- includes test card.

DEFAULT ACTION ROUTE:
user action → direct action first → inline status/result → fallback only if blocked.

DING CONDITIONS:
- new build starts from scaffold,
- v1.7 UX core present,
- copy/open/download route present,
- fallback is not default,
- build receipt states scaffold inherited.

NO DING CONDITIONS:
- new build starts from older legacy body,
- copy/open/download functions missing,
- manual fallback appears first,
- scaffold inheritance not receipted.
