- **Whole-Estate completion:** NOT CLAIMED. Other folders in `/JM Estate/`, including coding, games, engines, OS and historical archives, still need source inventory, safe transfer, and readback.
- **ZIP contents and binary artifacts:** NOT TRANSFERRED as part of this import. Merely importing a neighbouring Python or HTML file is not equivalent to importing every member of a ZIP package.
- **Keystores, private keys, credentials, and other private material:** DO NOT publish to this public repository. A signing-key / `.keystore` file exists in the Estate and was deliberately excluded. Source files were screened for several high-confidence secret patterns, which is not a security certification.
- **Hashes and evidence:** source text was read from ChatGPT Library and written to GitHub; selected GitHub files were read back and compared against the source text. Not every file has independent byte-for-byte archive verification or native execution.
- **No implied promotion:** Source presence is not execution; co-residency is not typed transport; receipts do not prove owner-device acceptance.
- **No changes to `main`:** this is an isolated import branch pending review.
