Full Current-Scope Sovereign Positional Route Coding Body — root law: 3 ↔ C | 2 ↔ B by alphabet placement.

32_Cb: the left rail 32 and right rail Cb can carry the same positional route and cross-check one another. The underscore _ is the local bridge/check separator.

BOUNDARY: this is a tested hosted web implementation of 32_Cb. It is not a claim that all Cading/CadenVM functions have been merged into it, nor that it is a native standalone runtime or universal cipher. MESH ≠ MERGE.

A–Z Position Rail

      

      
Bare digit strings are read one digit at a time for positions 1–9. Positions 10–26 require separators or brackets: 10.13, 10-13, or [10][13].

      
CASE ≠ POSITION. Numeric position recovers canonical uppercase identity, not source case. Source case remains metadata.
