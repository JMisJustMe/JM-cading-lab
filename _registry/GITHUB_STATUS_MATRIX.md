## Monetisation lens

GitHub does not create value by itself.

The finger-pair coding system creates value. GitHub makes value trackable, polishable, deliverable, recoverable, and easier to turn into demo/product/client routes.

## Corrected assistant role

When a body is available, the assistant should:

1. create or update the correct GitHub folder
2. add the file/body
3. create README/status/proof notes
4. mark route state honestly
5. avoid fake open links
6. prepare demo/release/monetisation candidate labels where appropriate
