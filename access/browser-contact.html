What a pass actually means

  1. Worker PASS: a real Web Worker on this browser/origin returned the expected data 32 times; this does not prove the protected CP04's five-worker system.
  2. IndexedDB PASS: browser storage wrote and read 32 independently identified records during this run; it does not prove crash recovery or another application's storage.
  3. Re-entry: a later page load can read the previous checkpoint. Reload the page to check. This is not a substitute for a physical Fold screenshot or a full crash test.
  4. Permission HOLD: this page cannot detect ChatGPT's site permission, logged-in status, background browser automation or MCP use; those require their own contact and receipt.
