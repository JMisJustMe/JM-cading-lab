# JM File Grabber × Visualang — Native Android v0.3

Native wrapper source for the File Grabber × Visualang intake body.

## Added over v0.2

- Android file multi-select.
- Android folder-tree selection.
- Persistable provider permissions where granted.
- Exact SHA-256 while copying into an app-private vault.
- Cross-restart vault metadata and exact-byte restoration.
- Private-vault bodies served to the Visualang HTML through a bounded local WebView route.
- Explicit clear-vault and native receipt routes.
- 500-file / 512 MB intake guards.
- GitHub Actions debug-APK build lane.

## Boundaries

- Source ancestors are never overwritten.
- The debug APK is not a production-signed release.
- Folder intake and cross-restart restoration become Android-proven only after installed-device testing.
- No live public website route is changed by this source package.
