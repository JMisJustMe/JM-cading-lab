# JM Estate Storage Steward v0.9B Native Border APK

A mount-once Android custody shell for the proven v0.9A Steward HTML body.

- Select the exact Steward HTML file on first launch.
- The source file is never modified; a private working copy is retained inside the app.
- Exports are written to `Downloads/JM Estate Storage Steward` through Android MediaStore.
- A native receipt shelf keeps stable open routes for generated receipts.
- No delete, move, rename, merge, overwrite, upload, or background-scan route is exposed.

This is a debug/field-proof build. Production signing is intentionally absent.
