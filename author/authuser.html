Why

Understanding becomes stronger when it can be contacted.

The variety is not the purpose. It is a consequence of the method. A personal observation can become a theory; a theory can become an interface; an interface can reveal a coding requirement; code can become a tool; a tool can expose a game mechanic; play can expose something new about interaction; the contact can send the creator back to the theory.

Find what is happening. Preserve what matters. Give it a body. Enter the body. Let reality answer. Correct what contact exposes. Make what survives recoverable. Then let it travel farther than its source.

Method

Contact before crown.

A compelling model is not automatically reality. A successful implementation does not prove exclusivity. A source does not become proof merely because it is sincere. The route is made visible so correction can improve the body rather than destroy the project.
