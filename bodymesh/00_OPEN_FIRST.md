## Purpose

BodyMesh is a separate backup and common-body build route. It does not replace JM Estate Compass, Estate Head, First Stage, Bringing It All Together, Theory Multihub, Library, Wisebase, GitHub, chats or Projects.

It receives those bodies as sources, keeps each source and identity traceable, finds tested common functions, groups related bodies without flattening them, and builds additional big byproducts that can be traced back to every component.

## Main route

**recover body > test strongest form > find shared function > keep differences > make Common-Body House > compile big byproduct > trace back to source and receipt**
