## Governing correction

Searching the JM ecosystem first is mandatory source intake. It is not permission to stop merely because JM Estate Compass, Estate Head, First Stage, Bringing It All Together, Theory Multihub or another body already contains overlapping material.

BodyMesh exists as a separate backup, source witness and common-body build route so one failed chat, project, register or carrier does not force the user back to First Stage.

## Main job

1. Recover individual bodies from all accessible sources.
2. Test their strongest presently evidenced forms.
3. Preserve older, rejected and alternate lineages.
4. Find genuine shared functions.
5. Make Common-Body Houses without flattening differences.
6. Compile larger usable descendants.
7. Keep every component traceable back to source and receipt.
8. Receive significant production-chat rebuilds and test whether they become current-best.

## Four layers

1. **Source Estate** — chats, Projects, Library files, Wisebase documents, GitHub source, OPEN_FIRST carriers, packages and receipts.
2. **Body Register** — each distinct creation, alias, state, strongest form, authority and source route.
3. **Common-Body Houses** — related bodies connected by an evidenced function while identities remain visible.
4. **Big Byproducts** — additional systems, engines, tools, houses, apps, books or other descendants actually compiled from housed bodies.

## Compilation law

**Mesh does not mean merge. Compilation does not erase composition.**

A common house or big byproduct is earned only when:

- a genuine shared function is shown;
- each component gives a distinct contribution;
- differences and boundaries remain visible;
- current-best comparison is performed;
- reverse trace reaches every source body and receipt;
- the joined descendant actually exists in an operational form;
- the descendant performs a capability that the family map alone cannot perform.

A family map, candidate name, schema, compile gate or architectural description is not yet a byproduct.

The descendant is additional. It does not replace its component bodies.
