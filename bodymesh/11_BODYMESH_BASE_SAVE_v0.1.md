Searching the JM ecosystem first is mandatory source intake. It is not permission to stop merely because JM Estate Compass, Estate Head, First Stage, Bringing It All Together, Theory Multihub or another body already contains overlapping material.

BodyMesh exists as a separate backup, source witness and common-body build route so one failed chat, project, register or carrier does not force the user back to First Stage.

1. **Source Estate** — chats, Projects, Library files, Wisebase documents, GitHub source, OPEN_FIRST carriers, packages and receipts.

**Mesh does not mean merge. Compilation does not erase composition.**

- a genuine shared function is shown;
- each component gives a distinct contribution;
- differences and boundaries remain visible;
- current-best comparison is performed;
- reverse trace reaches every source body and receipt.

The descendant is additional. It does not replace its component bodies.
