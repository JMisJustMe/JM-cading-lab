## Decisive correction

The estate target is not one generic kernel copied one hundred times and renamed.

The target is:

> **One hundred separately bootable kernels, each authored and generated through a different registered JM coding body, with all one hundred mountable inside one larger JM container without loss of identity.**

The container is a carrier, registry, selector and federation surface. It does not replace the kernels, flatten their source languages or become their source authority.

## Required route for every kernel

Each in-scope body must own this traceable route:

`body-native source`
`→ body lexer/parser`
`→ body AST`
`→ body semantics and permissions`
`→ body IR namespace`
`→ body compiler/runtime`
`→ body-specific kernel personality/source`
`→ shared proven machine carrier where appropriate`
`→ separate boot image`
`→ QEMU boot trace`
`→ body-specific fault/recovery receipt`
`→ freeze/lock/anchor`

A kernel does not pass merely because its name appears in a manifest or because a generic C identity structure was generated for it.

## What may be shared

The following low-level organs may be grafted from the proven RouteOS kernel lineage when their use is explicit and receipted:

- x86 or x86-64 entry glue;
- linker and image layout;
- descriptor-table setup;
- interrupt and timer plumbing;
- machine boot carrier;
- QEMU runner;
- common receipt and hash formats;
- PermissionGate, RouteScheduler, FaultHold and RecoveryBody interfaces.

Sharing these organs does not make the kernels identical, just as sharing a processor architecture does not make every operating system the same.

## What must remain body-specific

Every kernel must retain and machine-prove:

1. body ID and exact registered name;
2. governing law and source lineage;
3. body-native source file;
4. body-specific parser/compiler/SDK route;
5. body IR namespace;
6. kernel personality and declared operations;
7. permissions and capability profile;
8. trace format or trace identity;
9. fault identity and recovery route;
10. source, IR, binary and receipt hashes.

A kernel whose source is compiled only through a generic anonymous route is not yet a sovereign-body kernel.

The larger container may be named provisionally:

**JM EveryKernel OneContainer**

Its offices are:

- Kernel Registry;

- Isolated Run Lane;

The container must be able to:

- select and boot one kernel by exact body ID;

- run declared combinations through explicit OneBody contracts;
- record which kernel caused a trace, fault or recovery;

- package all sources, images, receipts and hashes recoverably.

## Separate-kernel machine gate

A body reaches `P7_INDEPENDENT_MACHINE` only when:

- its body-native source compiles through its own compiler route;
- its own kernel image is produced;
- QEMU boots that image;
- the serial trace states the correct body ID and law hash;
- at least one body-specific operation executes;
- one declared invalid action is contained or rejected;
- its recovery route executes where applicable;
- the trace and image are hashed and receipted.

## Federation gate

The estate reaches `P8_FEDERATION` only when the container proves both:

1. **isolated sovereignty:** each kernel can boot independently;
2. **collective cooperation:** multiple kernels can exchange through explicit contracts while preserving body ID, source authority, permissions, faults and receipts.

The collective proof may use a boot selector, nested carriers, a hypervisor-like coordinator, a multi-image runner or another JM-native container design. The mechanism may evolve; the non-flattening law may not.

## Anti-fake tests

The build must fail when:

- two kernels share the same body ID;
- a kernel is compiled by the wrong body compiler;
- a law hash is replaced;
- a source map points to another body's source;
- two supposedly separate kernel binaries are byte-identical without an explicit justified reason;
- the serial trace omits body identity;
- an anonymous fault is accepted;
- the container silently converts one body into an alias of another;
- a generated source stub is claimed as a QEMU Ding.
