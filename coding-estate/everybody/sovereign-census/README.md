# JM Sovereign Coding Census

Status: **OPEN / APPEND-ONLY / NOT CROWNED**

## Governing correction

The original CodeHouse 13 are a historical core, not the full coding estate. The current 100-body registry is the first engineering batch, not a final count.

Every evidenced sovereign coding body must enter this census and rise to at least **Cading / Quadze Plus** standard. A round number never closes the estate.

## Admission gate

A post-100 body must provide:

1. a stable ID and name;
2. a distinct executable or generative law;
3. body-specific capabilities;
4. source or estate-route evidence;
5. a sovereignty judgment;
6. known targets and gaps;
7. the `CADING_QUADZE_PLUS` parity floor;
8. an append-only ordinal.

Aliases, descendants, rooms, houses, tools and containers are not silently counted or silently discarded. They receive explicit identity judgment.
