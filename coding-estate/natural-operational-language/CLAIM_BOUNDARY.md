# Claim Boundary

This branch claims only a first functioning natural operational-language spine built on the current sovereign donor estate.

It does not claim:

- final semantics for ordinary words;
- historical recovery where only current-native implementations exist;
- universal natural-language understanding;
- complete compiler independence;
- completed federation execution from the natural-language surface;
- physical/device proof;
- final product or crown.

The branch must remain additive and reversible. Existing frozen/anchored bodies remain recoverable and authoritative within their own scopes.
