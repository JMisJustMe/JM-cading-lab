# JM Natural Operational Language v2.0 — Apps / Tools Classification

**Primary project:** Apps / Tools  
**Primary category:** Tool  
**Working type:** Creator Workspace / Management & Orchestration / Operational Interface

## Classification

The frozen v2.0 body is primarily a creator-facing management and operational workspace. Its current job is to manage meaning, operational word selection, room state, previews, commits, undo/redo, checkpoints, recovery, local rooms, wordbook definitions, permissions, export/import and routes into the wider JM Estate.

It is therefore classified under **Apps / Tools**, not Games.

## Game relationship

The game lineage is preserved as provenance and interaction DNA: act → see consequence → alter → retry/recover. Games may also be downstream bodies that this workspace can operate on.

That does **not** make the current v2.0 workspace itself primarily a game or game engine.
