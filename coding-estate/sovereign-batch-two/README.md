## Native identities

- **Kading** — keyed cadence programs, guarded beats and explicit recovery.
- **J’MP** — source-state jump maps with guarded cases, fallbacks and transition effects.
- **Codifying** — typed codices, constraints, deterministic records and emissions.
- **Kocodifying** — two-way identity-preserving bindings with conflict and rollback laws.
- **FormeULA / MarkeULA** — parameterised forms, dependency graphs, formula evaluation and yielded values.
- **Root Method** — premises, branches, rooted methods, provenance and visible consequence.
- **CadenVM** — frozen cadence opcodes, verified bytecode, deterministic execution and recovery.
- **THEO / PrimeBody** — staged source transformation where every stage emits a proof object.
- **JMVM** — frozen JM instruction set, checksummed bytecode, assertions, trace and mandatory Ding.
- **Polyglot Bridge** — explicit source/target contracts that translate state without collapsing identity.
