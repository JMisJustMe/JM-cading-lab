JM-native composition · supported input

Open the same box with your original AILatheo Creation Workbench v3 grammar: NAME : TYPE [#COLOUR] <SHAPE> :: ACTION. Currently supported actions: ToggleLight, TurnOn, TurnOff, Pulse, Spin, Grow, Shrink, Bounce. Shapes: circle, square, triangle, portal and line. Every imported body retains its name, type, colour, form and action. Native stage is a bounded local execution adapter, not the whole v3 workbench. Add LINK SPIDERSPY -> FLYYI and GOAL TRACE = 3 or GOAL TRACE = ON to compose distinct actions into a playable level. Cycles are bounded to one activation per body per touch. EXPORT EDITABLE APP emits a complete standalone HTML with its own visible code box, for every supported input type, not only JM-native levels.

Cading v1.0 line syntax also opens here, e.g. idea Ø, NOTA = observe.✓. It shows source operators, travel, landing, held state and receipt. It is a parser and visible mapping, not a general-purpose compiler. Plain HTML, JavaScript and CSS still work as before. CP10: Select HTML/CSS/JS together with PNG, JPG, GIF or WebP images; paths such as logo.png become embedded inside the one exported HTML. Sources and different coding-body identities remain separate.
