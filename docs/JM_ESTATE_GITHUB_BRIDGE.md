# JM Estate GitHub Bridge

## Active law

**Connect all to and through GitHub without flattening the Estate.**

GitHub is the shared public corridor, version history, registry and deployment route.

It is not a replacement for:

- owner-controlled phone and laptop source;
- Zionfolders;
- full archive ZIPs;
- USB-C / external-drive vaults;
- preserved historical bodies.

## Source boundary

The current local universal-editable Estate bodies are very large generated HTML wrappers. They are registered, but they must be split into normal source modules before responsible GitHub Pages deployment.

This is not treated as missing work or a reason to rebuild. It is a source-normalisation task:

`preserved local crown → extract modules → commit source → test routes → publish Pages body → receipt`

## Continuing route

Every body should ultimately have:

1. a stable repository path;
2. an identity and version record;
3. source files rather than only a generated wrapper;
4. a live or test route;
5. an edit/build route;
6. a receipt and proof state;
7. an owner-controlled archive copy.

## Locks

- Connect does not mean merge.
- Everything belongs in the index; not everything belongs in the same container.
- Selection before structure.
- Keeper before API.
- Proof before packaging.
- Recover before rebuild.
- No Ding, No Claim.
