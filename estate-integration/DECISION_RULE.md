# Integration vs rebuild decision rule

The Estate will integrate forward by default.

A from-scratch core rebuild is justified only if the existing bodies cannot be wired into one coherent runtime without breaking authority, canonical-door continuity, owner/public separation, recoverability or current proven functions.

## Proper integration means

- one stable public Estate root;
- one machine-readable authority/route registry;
- existing bodies remain sovereign modules with explicit roles;
- shared navigation resolves those modules instead of duplicating them;
- shared public status can be consumed by the public site and other safe surfaces;
- private owner/write capabilities remain private;
- Navigator is reconciled forward onto current main rather than merged as a stale whole branch;
- every claimed connection is proved by live route/contact evidence.

If those conditions cannot be achieved cleanly, build a new integration core and import the existing bodies as governed modules. Do not rebuild the bodies themselves unless their own source/runtime is defective.
