# JM Estate Sovereign Integration v1

This branch integrates existing Estate authorities without replacing or flattening them.

## Governing rule

One canonical public door may route to many sovereign Estate bodies. Carrier, host, proof, body, family, source authority and public route remain distinct.

## Integration scope

- Canonical public Estate door: Cloudflare `https://jmisjustme-estate.pages.dev/`
- Freestanding website lineage: InfinityFree v1.5 H1
- Private/logical owner source authority: JMISJUSTME Living Estate Owner Unified v1.11.1
- Current web/source navigation authority: JM Living MultiHub v6.0A
- Unified Browser current working descendant: JM3232 Unified Browser v1.1.2
- Navigator source authority: JM3232 Navigator Browser Bridge v0.1
- Navigator owner/live MCP descendant and separate public read-only OpenAI descendant
- JM Inline Contact as separate in-ChatGPT interaction lineage
- Singular Link MultiHub Registry as canonical-door/routing governance
- GitHub as source/version/recovery corridor

## What this integration must do

1. Preserve the existing canonical public root.
2. Publish one machine-readable authority/route registry.
3. Give the public site one stable integration endpoint that reports the currently governed routes and roles.
4. Keep private owner/write capabilities outside public surfaces.
5. Reconcile the stale Navigator live-contact work forward rather than merging its old branch wholesale.
6. Make later descendants update behind stable doors where possible.
7. Record proof separately from authority.

## What this integration must not do

- rebuild the Estate from scratch;
- silently replace Cloudflare with InfinityFree or vice versa;
- make GitHub the public Estate identity;
- merge Living Estate, MultiHub, Unified Browser, Navigator or Inline Contact into one body;
- expose private mutable Navigator/owner functions through the public registry;
- claim deployment, approval, review, owner contact or a Ding before it is actually observed.

This directory is a forward integration descendant of current `main`. Existing authorities stay untouched.
