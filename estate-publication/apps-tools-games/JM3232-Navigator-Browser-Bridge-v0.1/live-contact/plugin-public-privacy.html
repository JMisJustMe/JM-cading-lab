JM3232 Navigator — Privacy Policy

Effective date: 30 August 2026

JM3232 Navigator is a public, read-only Plugin for searching and retrieving governed JM Estate records, resolving RootWords, tracing source lineage, and inspecting the public bridge boundary.

Data the Plugin receives

The Plugin receives only the task-specific information ChatGPT sends to its five read-only tools, such as a search phrase, stable record ID, or RootWord. The Plugin does not request a user's full chat history, precise location, payment-card data, protected health information, government identifiers, passwords, API keys, MFA codes, or other authentication secrets.

Purpose

Inputs are used only to return the requested JM Estate search, record, RootWord, lineage, or bridge-status response. The public Plugin does not create user accounts, serve advertisements, sell personal data, profile users, or expose owner-only write functions.

Recipients and infrastructure

OpenAI sends Plugin requests to the JM3232 Navigator MCP endpoint. The endpoint is hosted on Cloudflare infrastructure, so Cloudflare may process ordinary technical network, security, and service logs under its own applicable terms and policies. The public Plugin does not call or scrape third-party content services; its source route is the first-party JM3232 Navigator service and governed JM corpus.

Retention

JM3232 Navigator's public Plugin does not persist user search terms, stable IDs, RootWords, or query history in application-controlled storage after the response is produced. Infrastructure providers may retain technical service logs according to their own policies and operational retention periods.

Public responses

Responses are deliberately minimized to public-safe fields needed for the requested task. The public Plugin does not expose owner runtime state, write receipts, Stringmarks, SavePacks, raw source excerpts, or shared mutable user state.

User controls

Users can stop using, disable, or remove the Plugin through ChatGPT. Users should not place unnecessary personal or sensitive information into search terms or IDs.

Age

The Plugin is intended for a general audience aged 13 and older and is not designed or marketed to children under 13.

Support and privacy questions

For support or privacy questions, use the public support route at JM3232 Navigator Support.
