# JM Apps / Tools / Games — Project & Chat Crosswalk v1.0

**Purpose:** prevent project/chat bodies from disappearing merely because no current ZIP was recovered in the publication sweep.

## Status language

- **SOURCE PUBLISHED:** readable runnable or buildable source exists on this GitHub branch.
- **KEEPER HASHED:** exact Library package identity, size and SHA-256 are in the machine register.
- **CURRENT HEAD — WAVE 2:** current keeper found but requires a separate source/public-safety pass.
- **ACTIVE CANONICAL ROUTE:** project/chat body governs future work but is not honestly a completed package.
- **FROZEN / DEVICE-PROVEN IDENTITY:** preserve and recover strongest source before rebuilding.
- **PRIVATE / OWNER CUSTODY:** never publish to this public repository.
- **OVERSIZE ROUTE:** requires Releases, LFS, split assets or another controlled carrier.
