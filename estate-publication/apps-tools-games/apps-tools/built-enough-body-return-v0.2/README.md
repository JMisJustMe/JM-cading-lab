# BUILT ENOUGH: BODY RETURN v0.2

A standalone, local-first SHIMS movement self-lab, routine generator and event-to-movement engine.

## Run it

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080`.

## What works now

- date-of-birth personal signature
- favourite-number anchor
- current-capacity calibration
- full routine generation and adaptation
- event-to-movement micro-return engine
- triggers for starting, finishing, celebrating, frustration, waiting and prolonged sitting
- environment-aware alternatives: floor space, wall/counter, chair and almost no space
- intention-only versions when physical movement is not appropriate in the moment
- local nudge scheduling and optional browser notifications
- full-session and moment-return receipts
- combined XP, levels, streaks and return totals
- BMI as an optional context marker only
- local browser storage, migration from v0.1, JSON export and offline PWA cache

## Reminder boundary

This version uses local browser timers. Reminders are most reliable while the page or installed PWA remains open. A closed browser may suspend timers. Reliable closed-app push notifications would require a server-side push service in a later version.

## Product boundary

This is a self-development and activity-logging prototype, not medical diagnosis, treatment or personalised clinical advice. The symbolic layer does not claim that birth dates or numbers medically determine the body.

## Reverse-engineering route

The working artifact is deliberately complete enough to act as a specimen. `REVERSE_ENGINEERING_MAP.md` separates its states, transformations, routes and receipts so they can later be re-expressed through JM coding bodies rather than merely renamed.
