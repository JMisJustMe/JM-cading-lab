# BODY RETURN v0.2 — Reverse-Engineering Map into Coding Bodies

This document treats the working app as a specimen. The purpose is not to rename JavaScript with JM terminology. The purpose is to identify the governing bodies that must later be expressed natively.

## 1. Persistent bodies

- **PROFILE BODY** — personal inputs and capacity markers.
- **SIGNATURE BODY** — transformed date/number pattern.
- **SESSION BODY** — generated multi-movement route.
- **MOMENT BODY** — current event and environment.
- **RETURN BODY** — generated micro-action.
- **RECEIPT BODY** — what actually occurred.
- **ADAPTATION BODY** — how later routes change.
- **NUDGE BODY** — future local prompt condition.

## 2. Primary transformations

1. `DOB + favourite number → signature`
2. `signature + capacity + movement choices → session route`
3. `moment trigger + environment + signature + capacity → micro return`
4. `completed action + reported response → receipt`
5. `receipt history → next-factor adaptation`
6. `nudge settings + time condition → moment prompt`

## 3. Route states

- UNPROFILED
- PROFILED
- ROUTE_READY
- MICRO_READY
- ACTION_ACTIVE
- RECEIPT_PENDING
- RECEIPT_RECORDED
- ADAPTED
- NUDGE_DUE

## 4. Governing choices

Every generated return must remain:

- swappable;
- adaptable;
- declinable;
- traceable to inputs;
- distinguishable from a medical claim.

## 5. Candidate coding-body operators

These are behavioural roles, not final syntax:

- `SHAPE` — derives pattern structure.
- `BOUND` — applies capacity and safety limits.
- `ROUTE` — chooses movement lane and expression.
- `PULSE` — converts an ordinary event into a prompt.
- `RECEIVE` — records what returned.
- `ADAPT` — changes future dose or route.
- `TRACE` — explains provenance of a generated suggestion.

## 6. Reproduction test

A JM-native implementation succeeds only when it can reproduce, from the same inputs:

- session structure;
- moment-return selection;
- dose boundaries;
- reminder conditions;
- receipt storage;
- adaptation behaviour;
- visible explanation.

Matching visual labels alone does not count.
