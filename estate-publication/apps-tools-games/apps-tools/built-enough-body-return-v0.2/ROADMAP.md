# Route Forward

## Phase 1 — Self-lab (active now)
- use the app personally
- complete and record sessions
- inspect where the symbolic pattern helps adherence
- inspect where capacity estimates miss reality
- adjust language and routine rules

## Phase 2 — Calibration users
- create consent-based profiles
- freeze the generator version before each test round
- collect accurate / partly accurate / inaccurate / too broad / unexpectedly useful feedback
- compare generated dose with actual completion and exertion

## Phase 3 — Product system
- multi-user accounts
- encrypted sync and backups
- expanded movement library
- richer adaptation rules
- accessible alternatives
- coach/practitioner mode

## Phase 4 — Game
- territories and quests
- streak recovery rather than streak punishment
- avatar/character progression
- cooperative challenges
- private leaderboards only when deliberately enabled

## Phase 5 — Return
- founding paid personalised programme
- premium app features
- practitioner licence or training
- partnerships where appropriate

## Non-negotiable

Do not let programme-building replace the physical practice. The creator remains the first live case.
