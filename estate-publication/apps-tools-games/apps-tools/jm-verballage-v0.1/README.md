# JM VERBALLAGE v0.1 — FIRST VILLAGE

A mobile-first, offline-capable story builder and connected story-village proof.

## Open first

Open `index.html` through a local static server or GitHub Pages route.

## JM bodies used

`IGNITIONBODY → ROUTEBODY → INPUTBODY → MOMENTBODY → STORYBODY → BIRTHBODY → LIBRARYBODY → VILLAGEBODY → TRACEBODY → RECEIPTBODY`

The JavaScript body powers the browser app. The C body proves the six-stage schema and build-gate validation can lower into a separate carrier without becoming the source authority.

## Core workflow

1. Build or generate a story.
2. Complete all six stages.
3. Save the story-house.
4. Inspect “Story and a Half”.
5. Choose a consequence and birth another story.
6. Open the Village map to see the relationship.

## Local data

Stories and trace receipts are stored in browser `localStorage`. Use Export Library regularly to create a portable JSON backup.
