# LiveForge Add-ons v0.1

## Add-on A — Recovery Gate
Checks whether a requested body exists before building from scratch.

## Add-on B — Claim Gate
Labels KNOWN / INFERRED / UNKNOWN / LIMIT / STRUCTURAL LOCK / PROOF-OUTPUT.

## Add-on C — Ding Gate
Creates a receipt only after route + state change are clear.

## Add-on D — Android Persistence Warning
Standalone downloaded HTML may not preserve state reliably; export JSON.

## Add-on E — Switchboard Handoff
Generates a text update for Central Switchboard.
