# Signuances Android source v1.0.0

Wave-2 public-source carriage for the governed Android carrier behind Signuances v1.0.0.

The five Android-project carriage blobs are reused directly from closed build-doorway PR #25. The embedded HTML is reconstructed from the already-canonical Signuances web publication on `main`; the 16 web-source blobs are not duplicated here.

Boundary: source only. APK/AAB, keystores, passwords, signing properties, private maintenance, owner signing and physical-device claims are excluded.
