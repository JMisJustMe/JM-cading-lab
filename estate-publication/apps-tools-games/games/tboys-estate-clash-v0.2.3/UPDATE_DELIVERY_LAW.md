# JM Game Update Delivery Law v1.0

Every game update must arrive as two separate user-facing bodies:

1. **Standalone HTML first** — a direct link for immediate trying.
2. **Fully packaged Zionfolder second** — the complete version-matched custody package.

The two bodies must carry the same version number and gameplay state.

A Zionfolder is not a substitute for the quick HTML link.  
A quick HTML link is not a substitute for source, receipts and recovery custody.

Each Zionfolder should contain, where relevant:

- the Open First HTML;
- README / re-entry route;
- native/source bodies;
- build and QA receipts;
- change log;
- evidence supplied during the preceding contact cycle;
- checksum;
- explicit Ding boundaries.

Keeper:

> **Try first. Custody second. Same update, both routes.**
