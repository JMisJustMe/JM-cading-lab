JM Rim Route · v0.8.2 · Android release candidate

Privacy

JM Rim Route is designed to play locally on the device.

This release candidate does not include advertising SDKs, analytics SDKs, account login, location access, camera access, microphone access, contacts access, or remote multiplayer.

Local game data

The game may save gameplay state and progression locally on the device using browser-style local storage inside the Android WebView. That information stays within the app's local storage unless the device or operating system provides its own backup or transfer behaviour.

Network use

The Android carrier does not request the Internet permission and the bundled game does not require a network connection for gameplay. External web links, if added in a future release, would open through the device browser rather than silently running inside the game.

Sharing and sale

This release candidate does not sell user data and does not contain a route that shares gameplay data with the developer or third parties.

Children and age

No final Play Store target-audience declaration is made by this local policy page. The developer must select and verify the intended audience in Google Play Console before public release.

Changes

If a later release adds online services, analytics, advertising, accounts, cloud saves, or other data routes, this policy and the Play Data safety declaration must be updated before that release is published.

Contact

Developer/support contact will be published with the final public privacy-policy URL at the Play Console account/release gate.
