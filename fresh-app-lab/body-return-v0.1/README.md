# BUILT ENOUGH: BODY RETURN v0.1

A standalone, local-first SHIMS fitness self-lab and routine generator.

## Run it

Open `index.html` directly, or serve the full source package with any static server.

The app does not depend on Base44, Wix, GitHub or another builder to exist. GitHub is the public proof/version corridor.

## What works now

- date-of-birth personal signature
- favourite-number anchor
- current-capacity calibration
- movement selection
- routine generation
- completion tracking
- RPE, mood, pain/symptom and notes receipt
- basic next-session adaptation
- XP, level and streak
- BMI as an optional context marker only
- local browser storage
- JSON export

## Product boundary

This is a self-development and activity-logging prototype, not medical diagnosis, treatment or personalised clinical advice. The symbolic layer does not claim that birth dates or numbers medically determine the body.

## Source custody

The downloadable multi-file package is the primary portable body. This folder is its live single-file proof and formal specification.
