## Sovereign role

GameForge is not another GlyphPlay stage editor. Its job is to preserve a selected game body while composing and compiling:

`Game Body → Input Loop → Play Loop → Consequence → Coding Body → Target`

## Working surface

- seven editable game-body contracts: T-Boys, Dragon Mirror, Route Catch, Core Clash, cardBORED, Humanimals and Blank Forge Body;
- six coding-body routes: GlyphPlay, Cading, Quadze, RECORP, FlowTalk and FormeULA;
- deterministic build graph and cartridge hash;
- identity-preservation proof: changing coding body changes the route while the selected game-body identity remains stable;
- dependency-free 2.5D isometric cartridge preview and playtest;
- responsive phone and laptop layouts;
- local save/load, project import, identity-bound cartridge export and genuinely self-contained playable export;
- PermissionGate, RecoveryBody, TraceBox and build receipts.
