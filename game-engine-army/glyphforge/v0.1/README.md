# GlyphForge Sovereign Rebuild v0.1 — First Adapter & Asset Floor

Engine 3 in **JM Game Engine Army — Sovereign Rebuild, Polish & Coding-Body Trials**.

## Sovereign role

GlyphForge does not compile whole game bodies like GameForge and does not replace GlyphPlay's creator/playtest identity. Its role is:

`Asset Body → Physical Input → Named Action → Adapter Contract → Visible Consequence → Trace / Receipt`

## Working first floor

- 12×12 pixel glyph editor with colour palette, draw/erase, mirror, rotate, duplicate and explicit deletion;
- asset library for player, enemy, wall, goal, projectile, effect, UI and marker bodies;
- adapter targets for GlyphPlay, GameForge, JM GameCore and Kading Game Estate Engine;
- explicit physical-input-to-action mapping with duplicate-route conflict detection;
- capability negotiation, required/missing states, FaultHold and RecoveryBody;
- repaired pull, pitch, fire and fling modes from the v67 lineage;
- keyboard, touch buttons, pointer drag/release and gesture routes entering one action dispatcher;
- dependency-free 2.5D isometric preview where every tested action visibly changes the field or emits a readable rejection;
- deterministic adapter identity, local save/load, round-trip JSON adapter import/export and self-contained demo export;
- phone and laptop layouts, TraceBox and receipts.

## Source lineage
