# JM Game Engine Army Visual Campaign v0.3 — Current Scope Boundary

## Earnable in this campaign

- nine distinct direct-file visual packages;
- one embedded portable launcher;
- one editable bundle;
- one HTTP/HTTPS PWA package;
- modular themes, FX, procedural audio, haptics, accessibility, performance and debug add-ons;
- desktop and Android-size screenshot smoke evidence;
- deterministic package hashes and receipts;
- preservation of the existing engine semantics and identities.

## Not honestly claimable from CI alone

- acceptable feel on the user's own Android handset;
- sustained editing and export/import use on real projects;
- authored character sprite sheets and animation direction;
- recorded music, voice and commercial sound design;
- advanced GPU/WebGL materials, post-processing and device profiling;
- native Android, Windows, macOS or Linux binaries;
- final polish or crown for any individual engine.

Current scope may be frozen only after the semantic, packaging, direct-file, screenshot and deterministic rebuild gates all pass on one head.
