# JM Game Engine Army — Visual Campaign v0.3

This package raises the nine current browser first floors without replacing their simulation or engine law.

## Governing boundary

- Existing engine state remains authoritative.
- Visual adapters observe and present state; they do not silently rewrite game rules.
- Every engine keeps a distinct material, motion, palette and information hierarchy.
- Phone and laptop are equal delivery surfaces.
- Direct-file HTML remains supported without module loading or remote dependencies.
- PWA installation is an additional HTTP/HTTPS package, not a replacement for direct-file delivery.

## Built-in add-on families

1. Theme Pack — four switchable visual materials.
2. Engine Identity Pack — nine body-specific palettes and motion signatures.
3. FX Pack — particles, route trails, pulses, contact ripples and restrained screen shake.
4. Procedural Audio Pack — user-gesture-gated Web Audio cues with no downloaded samples.
5. Haptics Pack — optional Android vibration cues where the browser permits them.
6. Accessibility Pack — reduced motion, high contrast, large touch targets, focus visibility and live status.
7. Performance Governor — DPR, particle and animation budgeting with automatic quality reduction.
8. Debug Pack — FPS and current engine/state indicators.
9. Visual Receipt Export — downloadable settings and package identity receipt.
10. Portable Launcher Pack — one direct-file launcher embedding all nine engines.
11. Editable Engine Packages — nine separate direct-file HTML packages.
12. PWA Pack — manifest, service worker and offline cache for HTTP/HTTPS hosting.

## Current claim

This is the strongest currently constructible browser visual/package layer. Real Android device profiling, authored sprite sheets, recorded music and sound design, GPU/WebGL materials, native binaries, sustained projects and final crowns remain open.
