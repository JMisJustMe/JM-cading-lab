# GlyphPlay Coding-Body Trials v0.1

The first benchmark seed is one editable 2.5D world. Each body changes its actual playable consequence:

| Body | World transformation | Primary route | Completion condition |
|---|---|---|---|
| Cading | Route marks | Mark → Signal → Route → State → Trace | Contact all marks |
| Quadze | Four ordered gates | Source → Contact → Change → Consequence | Complete gates 1–4 in order |
| RECORP | Scattered shards and centre | Scatter → Recover → Regroup → Lock | Recover and regroup every shard |
| FlowTalk | Context/meaning zones | Context → Signal → Response → Meaning | Contact all meaning zones |
| FormeULA | Formula-formed structures | Value → Relation → Form → Motion | Traverse all generated forms |
| ContactCode | Contact-state targets | Start → Hold → Release → Consequence | Complete governed contact cycles |

This is the first comparison surface. Later trials must preserve the same benchmark seed while deepening each body through its authoritative grammar, IR and runtime.
