## Common reusable organs to manufacture

1. **JM Game Body Loader** — selects a sovereign game adapter without merging identities.
2. **JM Input Intent Router** — converts touch, mouse or controller contact into game-native intents.
3. **JM TraceBox Unity Bridge** — records route, contact, impact, damage, state change and proof.
4. **JM Character Identity Definition** — movement word, handling, stats, visuals and signature behaviour.
5. **JM Arena / Field Definition** — materials, hazards, visibility, wind, cover and consequences.
6. **JM Round / Challenge Governor** — start, live, recover, reset, win and receipt states.
7. **JM Mobile Contact Layer** — touchscreen primary; buttons are complete backup routes.
8. **JM Build Receipt** — version, host, source body, proof target, result and known limits.
