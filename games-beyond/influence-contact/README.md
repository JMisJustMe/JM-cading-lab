# JM Games&Beyond — Gaming Influence Contact CP01

**One existing Games&Beyond House; no new front door and no substitute engine.** This addition imports a **private, owner-supplied** Google Play Takeout-derived `jm.gaming-influence-register.v1.1` JSON. It composes evidence-specific, *hypothetical* comparisons to already-existing JM rooms and loops, then invokes **actual JM PLAYFORM** for a traceable research contact. It never patches a playable game or renderer.

## Authority and reuse

- Source register: owner-private Google Takeout, available in JM's existing owner-edited Drive register (not copied to GitHub).
- JM native executable donor: `coding-estate/sovereign-batch-six/direct/game-input-native-b.mjs` → `PLAYFORM.execute`. This file and its underlying `native-core.mjs` are left unchanged.
- Receiving room/loop names recovered from `games-beyond/README.md` and `games-beyond/WHOLE_GAMES_ESTATE_RECONCILIATION_2026-09-20.md`.
- Review candidates are ten non-binding *mechanic questions*, not copied game content, affirmations of owner preference, or proof of any JM game upgrade.
- Recovered signals are separated as `GOOGLE_PLAY_INSTALL_RECORD` vs `DESIGN_HYPOTHESIS_NOT_RECEIVER_PROOF`.

## Host test from repository root

```bash
node games-beyond/influence-contact/influence-contact-selftest.mjs
```

This test uses **synthetic private-export-shaped records**, not the owner's history. It imports and executes the original native JM PLAYFORM. A passing Node run establishes source-level native contact only; no owner phone/laptop, browser, rendered scene, actual game integration or Gardles-native proof.

## Private owner record — optional local execution

Run from your owner-controlled repo checkout with your private JSON path (do **not** commit or upload this file):

```bash
node games-beyond/influence-contact/private-register-check.mjs /absolute/path/to/JM_GAMING_INFLUENCE_REGISTER_2026-10-29_RECONCILED.json
```

Returns totals, linked candidate titles and *one* native PLAYFORM contact/receipt without exposing device identifiers or dumping all installation records. Paths and install dates stay private. A game still requires its own source/gameplay/render/device/contact tests before any mechanics can be promoted.

## Boundary

- PLAYFORM source-to-research contact ≠ influence-based game rewrite.
- Public GitHub holds only executable adapter/test/source documents and synthetic fixtures, **not** the owner's private application history.
- Source integration ≠ public deployment ≠ browser interaction ≠ native Gardles ≠ owner-device gameplay.
- The original workbook, games, frozen ancestors, renderers and Gardles remain untouched.
