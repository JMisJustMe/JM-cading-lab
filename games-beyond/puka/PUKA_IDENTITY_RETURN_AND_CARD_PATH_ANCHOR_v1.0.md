# PUKA — Identity Return & Card Path Anchor v1.0

**Parent:** PUKA v0.17A — FLAZ parent  
**Purpose:** forward continuation anchor after current-body freeze

## 1. RETURN TO PUKA'S IDENTITY

The next development pass begins with the part already present but not yet dominant enough in the experience:

**PAUPER → ROYAL ASCENT → KING / QUEEN**

Progression should become visibly embodied in the game world, language, status, rooms/tables, rewards, presentation and player sense of rise. The goal is not to replace the existing poker/learning body, but to make its authored identity unmistakable.

## 2. TWO PRESENTATION BODIES — DELIBERATELY DIFFERENT

**Portrait Academy** remains the portrait-friendly, character-led, learning-first body.

**Royal Table** becomes a true horizontal/wide-table mode with its own composition, spacing, table theatre and information placement. It must not be a stretched Portrait Academy and must not become a second game authority.

Law: **ONE GAME AUTHORITY. TWO DELIBERATELY DIFFERENT PRESENTATION BODIES.**

## 3. THEN OPEN THE OTHER CARD GAMES PATH

Poker remains the first proved house. After the identity return and horizontal-mode pass, expand into additional card games one at a time, with the governing learning method:

**LEARN EACH GAME BY PLAYING IT.**

Reuse common card/deck, turn/state, teaching, trace, progression and presentation infrastructure where it genuinely transfers. Preserve the rules, feel, rhythm and identity of each receiving card game instead of forcing poker furniture onto it.

## CONTINUATION ORDER

**FLAZ v0.17A → PAUPER/ROYAL IDENTITY RETURN → TRUE HORIZONTAL ROYAL TABLE → OTHER CARD GAMES PATH**
