Current design locks

PvP by default

JM games should tend toward player-versus-player unless a story or solo mode is strong enough to earn independent play.

3v3 active arena

The current creature/team battle route should become a moving 3v3 field rather than a stagnant turn display.

Roster depth

Bigger character selections, more attacks, clearer roles and stronger movement identity are required.

Stadium mode later

A Pokémon Stadium-style presentation can become a separate future mode after the current active PvP body is stable.

2.5D / 3D baseline

Current prototypes may use placeholders, but the production direction is substantially stronger 2.5D/3D presentation and transitions.

Touch first

Touchscreen contact must be innate and understandable; buttons are backup. The player should know how to move and attack without reading a manual first.

Preservation rule

The earlier visual version is not deleted or rewritten. It remains frozen as a potential template for games suited to that style. The screenshot-led version is the current graft route.

Live gaps

  • Current attack input and feedback are not yet intuitive enough.
  • Graphics, animation, audio, balance and networking remain production work.
  • Unity source progress does not equal successful editor compilation or Android gameplay proof.
  • Do not crown a game because a design direction has been codified.
