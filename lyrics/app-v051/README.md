# JM LyricStudio v0.5.1 first-party mount

This folder carries the compact browser-native LyricStudio payload used by the independent `/lyrics/` route. It preserves the 121 Exiled Times bodies, Writer, Teleprompter, Studio, local state restoration and app-level Back handling.

The payload is staged in deterministic gzip/base64 parts so the deployment rail can reconstruct the exact checked body without flattening the rest of the Estate.
