JM3232 Navigator — Support

JM3232 Navigator is a public, read-only Plugin for governed JM Estate retrieval.

Get help

For technical problems, incorrect or unexpected results, privacy questions, or public-corpus concerns, open an issue in the JM-cading-lab repository:

JM3232 Navigator support issues

Please do not include passwords, API keys, MFA codes, payment information, health information, government identifiers, or other sensitive personal data in a support issue.

Supported public functions

  • Search the governed JM Estate
  • Fetch a public-safe source record
  • Resolve a RootWord
  • Trace public-safe source lineage
  • Inspect public bridge and Estate integration status

Owner-only Stringmarks, registrations, Stringreceipts, SavePacks, and mutable runtime state are deliberately not exposed by the public Plugin.
