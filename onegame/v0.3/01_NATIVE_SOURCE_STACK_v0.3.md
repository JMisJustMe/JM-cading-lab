## Native lock

### Cading

`touch → lifted aim → select → hold → grab → alter → release → commit → trace`

`seed → form → logic → play → trace → save → export`

The visible cursor point and the operational target must be the same point.

### Kading

Maps finger input, Living Cursor, body/organ target, state, action and trace without collapsing their roles.

### JMLogic

`FINGER ≠ CURSOR ≠ TARGET ≠ ACTION ≠ CONTACTBODY ≠ TRACE`

Off-field space must be deliberate or visibly flagged. Browser Ding, owner feel Ding and APK Ding remain separate.

### FlowTalk

Translates exact event bodies into readable action lines while keeping the exact event, data, time and proof kind beneath each line.

### RouteCode

Carries mode changes, centred rails, scene fit, nudge, recovery, source export and playable export.

### Quadze

Holds bodies, organs, cursor, target, ContactBody and receipt across CREATE / SHAPE / LOGIC / PLAY / TRACE / EXPORT.

### RouteOS

Owns local autosave, explicit save/load, undo/redo, contact-profile memory, rail-position memory and recovery into the preserved v0.2 branch.

### GameCore

Retains distinct game identities and real consequences while allowing shared organs.

### Visualang

Mode colour, body form, cursor position, human trace and exact receipt all speak operational truth rather than decoration.

### Contact Engine

- Thumb fit: aim lift −56, hold 220 ms, threshold 8, nudge 12.
- Precision: aim lift −78, hold 300 ms, threshold 5, nudge 5.

These are editable starting profiles, not universal physical prescriptions.

## Carrier boundary

HTML and JavaScript are the current browser carrier. They do not replace the JM-native source stack.
