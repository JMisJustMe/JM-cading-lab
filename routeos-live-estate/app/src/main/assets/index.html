      What this app proves—and what it does not

      It gives you a real, offline, playable and inspectable interface for the Five Crowns lineage. It does not boot the x86 kernel inside Android, replace the QEMU machine receipts, or claim that RouteOS is a general-purpose operating system. The kernel proof stays the kernel proof; this cartridge makes that proven work usable and understandable.
