## Agent operating entrance

Build Mesh carries two equivalent agent-facing forms:

- `AGENTS.md` — human/agent-readable nested operating entrance that inherits the Estate root instructions.
- `JM_SOVEREIGN_AGENT_CONTRACT_v0_1.json` — host-neutral machine-readable contract containing sovereignty, coding-body routing, proof layers, build preferences and re-entry law.
- `validate_agent_contract.py` — dependency-free static guard that rejects loss of the required sovereignty/proof/coding-body floor.

These are **route carriers, not current-head authority**. Compatible hosts may auto-read `AGENTS.md`; other hosts can consume the JSON directly. Platform adapters may add capability but do not own or redefine the body.
