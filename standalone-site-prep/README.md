# JMISJUSTME — Standalone Owner-Site Preparation v1.8

This branch stages the preparation contract for the standalone website without replacing the live `JM-cading-lab` root.

## Canonical GitHub form

- Account: `JMisJustMe`
- Dedicated repository to create: `JMisJustMe.github.io`
- Canonical GitHub Pages root after creation: `https://jmisjustme.github.io/`
- `JM-cading-lab` remains a connected coding corridor, not the website landlord.

## Public/private split

### GitHub public layer

Website source, public build, public registry metadata, receipts, documentation and small public web assets.

### Owner Estate layer

Private notes, private passports, source-chamber metadata, favourites, recent routes and mounted local bodies. These remain in browser storage and Full SavePacks unless deliberately published.

## Source Chambers

Holder chats, files, libraries, GitHub routes and archives can be registered as live Source Chambers while they continue self-sorting. Chambers move through `active-holder`, `forming`, `frozen` and `converged` states.

## Deployment body

The v1.8 package includes React/Vite source, a GitHub Actions Pages workflow, `.nojekyll`, 404 fallback, sitemap, robots file, public-data policy files and a GitHub-safe public-registry export.

## Honest boundary

The dedicated `JMisJustMe.github.io` repository does not yet exist. This staging branch records the prepared architecture and protects the existing live front door until the owner-site repository is created.
