# Source Chambers Intake Law

> The Estate should remember. The chat should think.

A current chat may remain an active workshop and self-sorting holder without being treated as the permanent source of truth.

## Chamber states

- **Active holder:** currently receiving and sorting work.
- **Forming:** one or more durable bodies are emerging.
- **Frozen:** protected for later return; not absent or discarded.
- **Converged:** durable bodies and receipts have crossed into the Estate.

## Minimum chamber record

- exact chamber name
- source type
- what it currently holds
- current state
- next intake action
- return route
- public/private visibility

## Intake rule

Register the chamber first. Ingest only the strongest current bodies and receipts. Preserve the chamber as source continuity. Do not flatten the whole conversation into a generic summary and do not call an unsearched body absent.
