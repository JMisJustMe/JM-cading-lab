# JMISJUSTME GitHub Storage and Deployment Law

## GitHub carries

- public website source and build
- public Estate registry snapshots
- receipts, schemas and documentation
- small public web assets
- release/version history

## GitHub must not carry by default

- private Owner Room notes
- private source-chamber contents
- API keys, passwords or secrets
- protected or unreleased bodies
- the only copy of any Estate body
- large archive payloads inside the Pages build

## Custody layers

1. **GitHub Pages:** lean public website.
2. **Git repository:** source, receipts, schemas and history.
3. **Browser Estate:** private local state and mounted bodies.
4. **Full SavePack:** portable owner backup.
5. **Releases/carriers:** versioned deploy and source packages.
6. **Later owner storage:** replaceable object/server/NAS layer for private cross-device scale.

## Address law

`content://`, `file://`, `blob:` and `sandbox:` are opening mechanisms, not the website address. The prepared GitHub root is `https://jmisjustme.github.io/`. A custom domain may later point at the same portable body.

## Build law

The public repository receives only a GitHub-safe public snapshot. Private passports, private chambers, notes and mounted body contents are excluded unless the owner deliberately publishes a selected body.
