# RouteOS v0.7 — Body-Native Basic OS Trunk

This gate preserves the v0.6 sovereign HTML cartridge route and corrects the ordinary utility layer so its state-changing behaviour is generated from distinct JM bodies.

## Route

`9 JM .jm.cading office sources → 9 OneBody identities → 9 generated JavaScript targets → RouteOS browser host`

and independently:

`the same 9 sources → 9 generated C targets → compiled native office ABI harness`

## Offices

FileBody, NoteBody, CalculatorBody, SettingsBody, SystemBody, TaskBody, PackageBody, VaultBody and PowerBody.

The host remains carrier metal: it renders views, extracts contact payloads and dispatches actions. It does not anonymously own the office mutations.

## Preserved sovereign route

The exact T-Boys HTML body retains SHA-256 identity, package authority, live-frame Quick Resume, additive controls and Save Vault custody. A hidden attached session bay allows TaskBody to hold and resume sovereign sessions while another office is visible.

## Boundary

This proves dual JavaScript and C lowering for the bounded office contracts, browser execution of the generated JavaScript offices and compiled execution of the generated C offices. It does not claim a full native desktop shell, disk-backed filesystem, POSIX compatibility, arbitrary C applications, production security or native kernel execution of HTML.
