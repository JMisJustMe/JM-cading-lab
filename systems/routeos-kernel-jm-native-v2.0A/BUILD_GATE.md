# JM Build Gate v2.0A

`source → entry → structure → behaviour → delivery → receipt`

- Source: fixed JM authority and generator.
- Entry: append-only integration into frozen v1.9A.
- Structure: retained offices and 128-event ledger.
- Behaviour: health, syscall, fault, quarantine, recovery and continuation.
- Delivery: ELF, ISO, observatory, add-ons and Zionfolder.
- Receipt: raw trace, JSON, symbols, disassembly, SBOM and SHA-256 ledger.

A failed route is not a failed task, but no failed route is represented as authority.
