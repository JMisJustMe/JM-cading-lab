# Claim Boundary

## Earned at construction time

- deterministic fixed JM source and generated C office;
- eight exact append-only integration hooks;
- local freestanding x86-64 C compilation against the frozen v1.9A integrated source;
- deterministic trace decoder, HTML/SVG renderer and Zionfolder packager;
- adversarial source-drift and duplicate-integration rejection;
- schemas, operator add-ons, SBOM and checksum routes.

## Requires live CI before claim

- linked ELF retention at exact symbols;
- bootable ISO after v2.0A integration;
- QEMU health PASS;
- structured fault, quarantine, recovery and continuation events;
- inherited Body 2 invalid-opcode containment exactly once;
- safe Body 1 continuation after recovery;
- complete release package generated from the live run.

## Not claimed

- persistent on-disk kernel logging;
- arbitrary process counts or a general process model;
- retrying a faulting instruction safely;
- dynamic fault-policy loading;
- filesystem, storage driver, networking, GUI compositor or shell;
- SMP, APIC/IOAPIC or multiprocessor recovery;
- arbitrary exception-family recovery;
- production security certification;
- a wholly JM-generated general-purpose operating system.
