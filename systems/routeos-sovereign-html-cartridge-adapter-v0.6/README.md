# JM Sovereign HTML Cartridge Adapter v0.1

## Purpose

Bridge exact first-party JM HTML bodies into RouteOS `JM-CARTRIDGE/1.0` without rewriting or flattening them.

## Proven donor foundation

- RouteOS v103.0 cartridge lifecycle and integrity standard.
- JM Game Engine Console v0.3 live iframe custody, Quick Resume, shared input bridge and exact touched-key Save Vault.
- Exact proof body: `00_OPEN_FIRST_TBOYS_CORE_CLASH_DIRECT_COMMAND_v0_3_JM_NATIVE.html`.

## Adapter route

`HTML source bytes → SHA-256 identity → JM-CARTRIDGE package → donor SDK validation → install → live iframe boot → hold → same-frame resume → additive control event → touched-key Save Vault → receipt`

## Security boundary

v0.1 is a **FIRST_PARTY trusted lane**. It does not loosen the existing declarative import boundary for untrusted packages. The source executes in a sandboxed iframe with `allow-scripts allow-same-origin` because Save Vault observation requires same-origin storage access.

## Honest limits

- Full page reload produces a cold resume.
- Older games may ignore additive controller events.
- Save Vault preserves exact values and keys; it does not interpret game-owned save schemas.
- This is a hosted browser adapter, not native kernel execution of HTML.
- APK lineage is recorded but no new APK is claimed in this bounded gate.
