# JM Game Engine Console v0.3 — Shared Runtime Contract

## Purpose
Carry live game sessions across the Games&Beyond House without collapsing or rewriting sovereign game bodies.

## Console owns
- live iframe custody while the Console page remains open
- hold, exact in-memory resume and quick switching
- shared Hands action profile and additive bridge events
- observation of exact localStorage keys a mounted body touches
- Save Vault capture, restore, import and export of those exact values
- launch/time/session trace and receipts

## Game bodies keep
- source authority and version lineage
- rules, simulation, rendering, interface and native controls
- the meaning and schema of their private save values
- internal proof and crown status

## Honest boundaries
- A held frame survives library and Estate-room movement while this page remains alive. A full page reload creates a cold resume.
- The Console publishes `jm-console-action`, `jm-console-input-profile`, `jm-console-hold` and `jm-console-resume`. Older bodies may ignore them until rejuvenated.
- Save Vault copies exact touched keys. It does not claim semantic understanding of game-owned saves.

## Law
No restart. No collapse. Connected is not collapsed. Live session is not rewritten game. Proof before crown.
