# BRAIDGE × Tied-Bridge Separators — Source-contact CP01

Status: **candidate interpretation; not a new sovereign body; no live MCP modification claimed**.

## Recovered foundation

BRAIDGE = bridge + braid + return: source-preserving passage, independently identifiable strands, trace, recovery and continuation. The full BRAIDGE master document and any current private source authority must be consulted before promoting a specific transfer operation to implemented capability.

## Working distinctions

- **Identity**: the original strand/source and its provenance; unchanged unless independently authorized.
- **Relationship**: which braid or context a strand participates in; may change without identity transfer.
- **Authority**: who may approve modification, copying, transfer, publication, or deployment.
- **Evidence**: source contact, runtime proof and inherited proof are separate claims.

## Candidate transitions (not verified implementations)

| Transition | Required distinction | Negative case |
| --- | --- | --- |
| Transfer | participation moves, source identity remains | moving participation is not automatic ownership transfer |
| Extension | another context gains access | access does not confer edit authority |
| Branching | descendant has distinct lineage | descendant is not identical to ancestor |
| Return | recoverable trace to source | absence of trace is not proof of return |
| Breakaway | independent continuation with declared lineage | separation is not erasure of origin |
