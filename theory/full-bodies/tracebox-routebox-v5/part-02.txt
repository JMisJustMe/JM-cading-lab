7. The Four State Families

Intake

Receives, primes, loads, accepts.

Examples:

Ready Intake, Late Intake, External Intake, After-Contact Intake

Output

Releases, shows, broadcasts, acts.

Examples:

Premature Release, Clean Activation, Early External Signal, External Release

Boundary

Blocks, protects, contains, seals.

Examples:

Blocked Output, Protected Boundary, Suppressed Leak, Quarantine / Isolation

Memory

Holds, preserves, recalls, stores.

Examples:

Stored Potential, Locked Memory, Contained Result, Sealed Consequence

8. Route Operators

Operators are how the route becomes behaviour.

Force — applies push / pressure / cause
Lift — raises something
Slide — moves something across a route
Drag — resists, pulls, or slows movement
Hold — keeps state in place
Release — lets stored state move
Delay — waits before result
Reset — returns to start
Split — divides the route
Merge — combines routes
Block — stops movement
Store — preserves condition
Trigger — activates next step
Trace — leaves readable record
Observe — sees/measures the route, possibly changing it

Keeper:

Operators are how route becomes behaviour.

9. Observation Layer

TraceBox includes an observation check.

This is related to the observer effect, but it is not the same thing.

Observer effect asks:

Did measuring change the system?

TraceBox asks:

What entered?
What changed?
What was seen?
What was altered by seeing?
Can the route be recovered?

Observation types:

Passive View
Active Measurement
Social Observation
Language Observation
AI Observation
Self-Observation
Hidden Observation
Delayed Observation

Keeper:

Seeing the route can become part of the route.

10. Version Ladder

v1 — Model

Defines the route-state logic.

v1 models.

v2 — Simulator

Runs inputs through gates and operators.

v2 simulates.

v3 — Calibration

Compares expected result with actual result.

v3 calibrates.

v4 — Observation

Checks whether seeing, measuring, naming, or tracing changes the route.

v4 observes.

v5 — Multi-Domain Route Engine

Applies the same route logic across physical, digital, human, language, AI, game, story, music, invention, and public-output systems.

v5 routes across domains.
