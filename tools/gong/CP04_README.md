# JM GONG CP04 — Public-Safe Evidence Scope Request

This is an **additive, read-only companion** to CP03 and the protected GONG CP04 evidence engine stored in JM Library. It never contains owner Fold screenshots, screenshot hashes, personal sources, or certified private proof registry, and cannot issue a fresh device PASS. It classifies which **prior evidence scope** would be relevant and how narrow any new test should be.

The private CP04 engine independently compares actual source/target bytes against a Library-recovered proof record. This public adapter only processes the bounded CP03 diff receipt. It does not assert any actual owner proof is available in this repository.

Commands: `node --test tools/gong/tests/gong_scope_cp04.test.js` or run the `JM GONG CP04 — evidence scope requests` workflow. Existing JM intake, release and device evidence gates remain intact. **Private evidence lookup is not automated into public CI**, and any decision to merge is separate. No automatic device-check escalation to the owner.
