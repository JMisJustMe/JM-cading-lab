# JM Estate — Visual Systems Lab v0.1.0

A living visual workshop built from JM coding bodies from the beginning.

## Open

- `index.html` — live visual laboratory
- `00_OPEN_FIRST.html` — status, architecture and claim boundary
- `visual-lab.cading` — source-side route seed
- `registry.json` — bounded capability and delivery registry

## Native body route

`visual-lab.cading → JMOneBody/JMLogic → JM Visual Interaction Runtime/JMVisualGraft → RouteFrame/StateField/ContactBand → TraceBox/Dings → PWA + Capacitor host`

The host serves delivery. It does not replace source authority.

## Current rooms

1. Illusion Field — four code-native illusion engines, observation and measure trace.
2. Image Field — local source, non-destructive preview treatment, compare and PNG export.
3. Video Field — local source, playback speed, frame step, contrast and storyboard capture.
4. Motion Field — connected-difference orbit, tunnel and breathe experiments.
5. Visualang Prompt Forge — governed visual brief formation without pretending a generator is connected.
6. Story Rail — image/text intake, captions, ordering and JSON export.

## Controls

Touch/pointer and keyboard share one ContactBand. Keyboard: `1–6` rooms, `←/→` route, `Space` primary contact, `R` recovery, `T` TraceBox.

## Website / PWA / Android

The route is a static installable PWA. `package.json` and `capacitor.config.json` establish the Android source carrier. A compiled or signed APK/AAB is not claimed in v0.1.
