## Native body route

`visual-lab.cading → JMOneBody/JMLogic → JM Visual Interaction Runtime/JMVisualGraft → RouteFrame/StateField/ContactBand → TraceBox/Dings → OneBody delivery → PWA + Capacitor Android host`

The host serves delivery. It does not replace source authority.

## Current rooms

1. Illusion Field — four code-native illusion engines, observation and measure trace.
2. Image Field — local source, non-destructive preview treatment, compare and PNG export.
3. Video Field — local source, playback speed, frame step, contrast and storyboard capture.
4. Motion Field — connected-difference orbit, tunnel and breathe experiments.
5. Visualang Prompt Forge — governed visual brief formation without pretending a generator is connected.
6. Story Rail — image/text intake, captions, ordering and JSON export.

## Controls
